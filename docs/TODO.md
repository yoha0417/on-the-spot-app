## Phase 1: 認証の貫通（すべての土台）
- [ ] **1-1. ログイン・登録のAPI疎通**
  - ダミー関数を実際のAPI呼び出し（`apiClient.ts` / `fetch`）に置き換える。
- [ ] **1-2. 認証状態のグローバル管理**
  - `SecureStore` を用いたトークン・ユーザー情報の保存。
  - `AuthContext` を作成し、アプリ全体に「ログイン中である」状態を提供する。
- [ ] **1-3. UIへの反映とガード**
  - ドロワー（サイドバー）やマイページにユーザー名を表示する。
  - 未ログイン状態でチェックイン等の保護された操作をしようとした場合、ログイン画面へ強制リダイレクトさせる。

## Phase 2: コア体験（マップとチェックイン）
- [ ] **2-1. 周辺スポットの取得とピン表示**
  - ダミーの現在地（緯度・経度）をAPIに送信し、周辺スポットを取得。
  - マップ上に「赤以外のピン（例: 青や緑）」で取得したスポットを描画する。
- [ ] **2-2. ピンのタップとチェックインUI**
  - ピンをタップした際、画面下部にBottomSheet（またはモーダル）を表示。
  - スポット名と、「チェックイン」または「チェックアウト」ボタンを状態に応じて表示する。
- [ ] **2-3. チェックイン状態の管理と警告ポップアップ**
  - 「現在どのスポットにチェックインしているか」をContextでグローバル保持する。
  - 別の場所にチェックインしようとした際、「現在〇〇にチェックイン中です。チェックアウトしてこちらにチェックインしますか？」という警告ダイアログを実装。

## Phase 3: タイムラインと画像投稿（最難関）
- [ ] **3-1. タイムラインのルーティング制限**
  - タイムラインタブを開いた際、Contextのチェックイン状態を確認。
  - どこにもチェックインしていない場合はマップ画面へ強制リダイレクトし、Toast等で警告を出す。
- [ ] **3-2. タイムラインの表示と「いいね」**
  - チェックイン中のスポットに紐づく投稿一覧をAPIから取得・表示。
  - 「いいね」ボタンのAPI疎通と、楽観的UI更新（Optimistic UI: 押した瞬間に数字を増やす処理）の実装。
- [ ] **3-3. Cloudflare R2への画像アップロード**
  - WranglerによるローカルR2エミュレート環境の活用。
  - フロー: ①バックエンドにPresigned URLを要求 → ②アプリから直接画像PUT → ③投稿完了をバックエンドへ通知。

## Phase 4: マイページと仕上げ
- [ ] **4-1. マイページの実装**
  - プロフィール情報、過去の自分の投稿一覧のAPI疎通。
  - アイコン画像の登録機能（Phase 3のアップロード基盤を流用）。
- [ ] **4-2. 自動チェックアウト機能（ジオフェンス）**
  - ダミー現在地と、チェックイン中のスポット座標の「距離」を計算（`geolib` 等を利用）。
  - 一定距離（例: 100m）以上離れたら自動でAPIを叩き、Contextのチェックイン状態をクリアする。
